1945 is a sample academic project based on an arcade game. 
The game is written in C and developed using the Raylib library

How To Play

  1. Download the files at this link [https://drive.google.com/file/d/1kKdvbWyWvUaawBOeGT_dzYqKe2TyzT-_/view?usp=drive_link]

Controls

WASD - Move
Space - Shoot

Gameplay

Survive as long as possible while destroying enemy planes.
